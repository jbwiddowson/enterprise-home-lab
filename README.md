# Enterprise Cybersecurity Home Lab

## Overview

Built a simulated enterprise network environment using a rack-mounted server
and virtualization technologies to practice system administration,
network security, SIEM monitoring, threat detection, and incident response.

This lab serves as the foundation for multiple cybersecurity projects,
including SOC operations, threat hunting, vulnerability management,
and penetration testing.

---

# Objectives

- Build an enterprise-style network environment
- Deploy Active Directory infrastructure
- Implement centralized logging and monitoring
- Simulate cyber attacks and analyze detection methods
- Practice defensive security operations
